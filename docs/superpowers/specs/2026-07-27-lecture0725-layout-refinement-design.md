# 2026-07-27 装卦六亲课程版式修正设计

## 目标

修正新版课程页中单卦详情、六亲生克、父母爻与官鬼爻、判断边界及古籍学习路线的视觉与状态问题。经典版保持不变。

## 一、单卦详情统一上移

- 适用范围：八宫全部 64 卦的单卦详情。
- 从“单卦取象 · X宫 · X世”到最下方“X宫 · 宫五行X · 第XX卦”视为一个完整内容组。
- 保留内容组内部现有视觉节奏，不通过压缩卦象、标题或说明之间的间距来解决问题。
- 在各断点统一的最小视觉高度内，将完整内容组统一上移；容器仍须允许内容向下增长。
- 上移后的验收基准：内容组上边缘到宫位导航区域的留白，与内容组下边缘到背景边界的留白在视觉上相等。
- 当前 64 卦在同一断点使用相同宽度、最小视觉高度、内边距和定位基线；现有文案应呈现等高，不得因标题或说明长度不同产生尺寸跳动。
- 容器必须保持 `height:auto; max-height:none` 的增长安全策略，避免文字缩放或未来文案增长时被裁切；增长后的内容优先完整显示，而不是强制锁死高度。
- 桌面、平板和手机分别设定一致的响应式最小高度规则，手机端同样保留上下近似等量留白。

## 二、六亲生克图

- 取消当前以两列文字关系为主的表现。
- 参考基础讲义“五行生克图”的图形记忆方式，采用双环五行图。
- 外环呈现木、火、土、金、水及相生方向；内层呈现相克关系。
- 图中以宫五行为“我”，通过高亮或中心标识映射五类六亲：
  - 生我：父母
  - 同我：兄弟
  - 我生：子孙
  - 我克：妻财
  - 克我：官鬼
- 桌面端保持完整双环，移动端按比例缩放，不退化为纯文字列表。
- 补充简短图例用于消除箭头方向歧义，但图例不得成为主体。

## 三、父母爻与官鬼爻

- 两张卡片保持相同宽高。
- 标题、关系说明、人物、事物、状态及“使用边界”采用统一网格和相同起始基线。
- 各分类列设置一致的列宽、间距和最小高度。
- “使用边界”固定在卡片底部的同一水平位置；较长文字允许自然换行，但不得挤压或错位。
- 移动端转为单列时，仍保持每张卡片内部相同的标签宽度与文本缩进。

## 四、判断边界

- 重建为明确的标题区、判断规则区和底部说明区。
- 标题与规则列表顶部对齐；规则列表使用统一缩进和行距。
- 底部说明横跨整行，独立分隔，并保持稳定内边距。
- 移动端改为单列后，标题、列表与说明按阅读顺序排列，不出现悬空或左右错位。

## 五、古籍学习路线

- 将“装卦”和“六亲”从“古籍预习”状态调整为“已学习”。
- 已学习状态沿用现有已完成步骤的颜色、节点和连接线。
- 古籍原文校注仍可作为后续深化内容，但不得把课堂已经讲授的主题继续标为未学习。
- 其余仍未讲授内容维持原状态，不扩大完成范围。

## 实施边界

- 仅修改新版课程副本及其对应发布源，不修改仓库内受保护经典树 `liuyao-study-20260718/` 或 Obsidian 经典版目录。
- 优先使用现有 DOM 和 CSS 结构；仅在无法稳定对齐时增加必要包装层。
- 不修改课程事实、题库题目、掌握度算法或本地存储结构。
- 不改变现有入口与新版 URL 参数。

## 验证

1. 为上述布局状态补充或更新自动化断言，并先确认旧实现不能满足新断言。
2. 运行现有完整测试集。
3. 在桌面、平板和手机视口检查：
   - 当前 64 卦在各断点宽度与视觉最小高度一致，最短和最长现有文案实际等高；
   - 放大文字或注入更长文案时容器可以增长，且页脚与正文不被裁切；
   - 单卦内容组上下留白视觉相等；
   - 双环五行图无裁切、箭头方向清楚；
   - 父母爻与官鬼爻各区块对齐；
   - 判断边界无错位；
   - “装卦、六亲”显示为已学习。
4. 对仓库内 `liuyao-study-20260718/` 受保护经典树及 Obsidian 经典版目录分别重新计算哈希，并与各自修改前基线比较，确认零改动。
5. 发布后复查新版直连和默认经典版隔离。
