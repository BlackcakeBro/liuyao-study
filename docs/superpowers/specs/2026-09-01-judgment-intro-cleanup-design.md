# 断卦页首清理设计

## 目标
将断卦页首背景扩展到与下方内容同一水平宽度，并移除面对学习者的课程制作与复核说明。

## 设计
- 保留页首的主题、知识内容和学习进度入口；将 `.judgment0822-intro` 的最大宽度限制取消，使其跟随 `.view` 的内容宽度。
- 删除两处“全程复核/时长/屏幕共享/音轨”状态条，并将引言改为纯学习内容说明。
- 清理题库来源中的录制时长和复核措辞，保留教师与课程日期作为来源标识。

## 验收
- 断卦页首背景与本页下方内容水平对齐。
- 扩展版 HTML 和题库不再出现面向学习者的制作说明词。
- 既有课程内容、题库题目、经典版隔离不变。
